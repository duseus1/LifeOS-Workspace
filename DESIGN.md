# LifeOS interface

The approved drawing fixes the homebase hierarchy. Operate mode: fast capture, calm reading, no decorative dashboards or invented records.

Use a warm paper background (#f6f5f1), white panels, ink (#242b28), muted green (#45664e), restrained borders (#dedfd7), 14px panel corners, no card shadows. System text for familiar desktop controls; Georgia for the Homebase title. Compact navigation drawer, generous writing measure, clear focus and status text. Dark mode uses deep green-gray surfaces and light neutral text. All colors use documented CSS variables.

Tasks/reminders share the first row; calendar and Quick Notes span the width. Mobile stacks sections. Empty states invite one real action. Settings and capture use focused dialogs with labels, Escape and focus management. Do not introduce sample personal data.
